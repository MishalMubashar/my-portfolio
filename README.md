# Mishal Mubashar — Playful Cartoon TV Portfolio

A responsive personal developer portfolio with a light pastel palette, project cards, interactive filters, and a CSS-animated retro TV featuring playful cartoon characters.

## Files
- `index.html` — portfolio content and layout
- `style.css` — responsive styling and TV/cartoon animations
- `script.js` — animated intro text and project-card filters

## Run locally
Open `index.html` in a browser, or use the Live Server extension in VS Code.

## Deploy
Push these files to the root of your existing GitHub repository and connect that repository to Vercel (or another static hosting service). No email API, Gmail App Password, environment variables, or backend function is required because the contact form has been removed.

## Academic details
The education figures remain labelled as goals. Only change them to achieved results if they are confirmed.
